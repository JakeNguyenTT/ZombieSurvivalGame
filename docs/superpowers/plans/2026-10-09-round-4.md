# Round 4 Implementation Plan

> **For agentic workers:** Executed inline (superpowers:executing-plans style). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tune balance from measured bot play, stop the font asset churning, and make the Android build lighter.

**Architecture:** A `BotPlayer` component plays the real game through the same input path as a human (StarterAssets inputs) and picks upgrades with a simple policy. An `[Explicit]` PlayMode test runs many seeded games at a fixed 1/30 s step (`Time.captureDeltaTime`, so the game runs as fast as the CPU allows without changing physics step size) and writes one JSON line per run. Tuning changes land in data assets and `Difficulty`, guarded by the existing tests. Android gets its own URP asset (render scale + STP upscaling) on its default quality level and an `AdaptiveQuality` component that lowers render scale when frame rate drops.

**Tech Stack:** Unity 6000.6.5f1, Pipeline CLI (live Editor), Unity Test Framework, URP 17.6.

## Global Constraints

- Branch `feat/round-4`; fast-forward `main` by ref; push deferred.
- Simulation restores PlayerPrefs and Time settings afterwards; runs with no meta upgrades and the Soldier.
- Balance targets (bot, Soldier, no meta): median survival 6–12 min; first boss killed in ≥ 60% of runs; no death before 2:00 in ≥ 90% of runs.

---

### Task 1: Bot + balance simulation + tuning

**Files:** Create `Scripts/Bot/BotPlayer.cs`, `Scripts/Bot/BotUpgradePolicy.cs`, `Tests/PlayMode/BalanceSimulation.cs`; modify data/`Difficulty` as results dictate.

**Decisions:**
- Movement: sum of repulsion from enemies within 9 u (weight 1/d²), attraction to the nearest gem within 12 u, a sideways orbit term so it circles instead of backing into a corner, obstacle repulsion within 3 u, soft pull back toward the start beyond 60 u. Converted to camera-relative input for `StarterAssetsInputs.MoveInput`.
- Upgrades: evolve > weapon card (new or level-up) > heal when below 50% > damage / fire rate > max health > anything else; rerolls unused.
- Simulation: seeds 1..N, cap 15 min game time, record per run: seed, survival time, cause (death/cap), kills, level, bosses spawned/killed, weapons with levels, HP at 2/5/10 min; write `Temp/Balance/results.jsonl`.
- [ ] Implement bot + harness; run baseline (N=12); tune; re-run until targets met; commit with before/after numbers.

### Task 2: Static font atlas

- [ ] Pre-populate `shlop SDF` with printable ASCII (32–126) and switch it to Static so test runs and play stop rewriting it; verify all game text still renders (screenshots); commit.

### Task 3: Android rendering + adaptive quality

**Files:** Create `StarterAssets/.../MobileURPAsset.asset` (copy of the default URP asset: render scale 0.8, STP upscaling, shadows reduced) assigned to quality level 2 (Android/iOS default); create `Scripts/Manager/AdaptiveQuality.cs` (mobile only: lowers render scale in 0.1 steps to 0.6 when frame time averages > 22 ms over 3 s, raises back when < 15 ms).
